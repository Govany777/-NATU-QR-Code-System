# NATU Attendance Recording System (QR Code)

A modern, web-based attendance tracking system designed for NATU, featuring QR code scanning, glassmorphism UI, and administrative controls.

## 🚀 Features
- **Student Registration**: Easy enrollment with profile photo management.
- **QR Code Integration**: Generate and scan QR codes for quick attendance recording.
- **Glassmorphism Design**: Sleek, modern, and responsive user interface.
- **Admin Dashboard**: Comprehensive tools for managing students and viewing attendance records.
- **Security**: Passcode-protected access for attendance recording and admin functions.

## 🛠️ Tech Stack
- **Backend**: Python (Flask)
- **Database**: SQLite
- **Frontend**: HTML5, CSS3 (Vanilla), JavaScript
- **Scanning**: HTML5-QRCODE library

## ⚙️ Installation & Setup
1. **Clone the repository**:
   ```bash
   git clone https://github.com/Govany777/-NATU-QR-Code-System.git
   ```
2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
3. **Run the application**:
   ```bash
   python app.py
   ```
4. **Access the app**: Open `http://127.0.0.1:5000` in your browser.
